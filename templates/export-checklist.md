# Export checklist

An export is a file your tool gives you with one row per sale or per lead. Look for a button called Export, Download or CSV on the list screen.

Use the same 7 days for both files: last Monday through last Sunday.

## 1. Sales export (from your checkout tool)

Keep these columns:

- [ ] Date of the order
- [ ] Product name
- [ ] Amount paid
- [ ] Source: where the buyer came from. It may be called source, referrer, campaign or UTM.
- [ ] Status, so refunds and failed payments can be left out

Delete these columns before you share the file:

- [ ] Customer name
- [ ] Email and phone
- [ ] Address
- [ ] Anything about the card

## 2. Leads export (from your CRM or signup form)

Keep these columns:

- [ ] Date the person joined
- [ ] Source or tag: how they came in
- [ ] What they signed up for, if you have more than one freebie

Delete these columns before you share the file:

- [ ] Name
- [ ] Email and phone

## 3. If your tool has no source column

That's a finding, not a failure. Write it down. Your report will say "sales by source: not counted", and now you know the first thing to set up.

Until then, you can still count by hand for one week: ask each buyer how they found you, or look at which link they used.

## 4. If you can't export at all

Read the totals off the screen and type them in:

- Number of sales and dollars, per source if you can
- Number of new leads, per source if you can
